## Rules in brief

- One group of three; one GitLab repository per group is provided and GitLab use is compulsory.
- Must achieve at least 40% on the group project.
- Everyone contributes to all aspects (design, implementation, testing, report); individual contributions are moderated using GitLab history and peer assessment.
- Report and code must be reproducible by the lecturer, and reported results must match the submitted code and output images.
- Raise any group problems early (a group interview with all members may be called).

## Working agreements

- The task owner drives the task; the other two review key design choices and integrated results.
- Everyone contributes across design, implementation, testing and the report (peer assessment covers all four).
- Everyone commits their own work to GitLab so individual contributions are visible.
- Extra credit only after a valid baseline and a working detector.
