Class balance

The classes have a small imbalance (69:55 = 1.25:1). The train set is almost balanced (49:45). The test set has a ratio of 2:1 (20:10). The loader augmentation changes the balance. It makes 10 samples from each face image (original, flip, 4 one-pixel shifts, 4 shifted flips). It makes 4 samples from each non-face image (original, LR, UD, LR+UD flips). Thus, the augmented train set has 490 face vs 180 non-face samples (2.7:1), and the augmented test set has 200 vs 40 (calculated from the code, not run).

Mean face vs mean non-face

The mean face image shows a clear face at the centre. The eyes are dark, and the cheeks and nose are bright. The corners are dark (hair and background). Thus, the crops are tight and the faces are aligned (eyes at approximately 1/3 of the height). The mean non-face image also looks a little like a face (pixel correlation 0.69). The cause is that some non-face images show partial or off-centre faces (hard negatives).

Observations
  • Face images: the faces are frontal and upright. Each crop goes from approximately the eyebrows to the chin. The lighting changes much (strong side light on 2–4 and 21–25, very dark on 16–20 and 59). Some persons occur more than one time (for example, 6–10 look like the same man). Some faces turn or tilt a little.
  • Non-face images: these show textures (keyboard 12–13, leaves or noise 15 and 54–57), flat areas (1, 17), clothes, doors and background. Some are hard negatives that show partial or shifted faces (for example, 14, 20, 26, 52, 53).
  • There are no exact duplicates (MD5 of the pixel data). Near-duplicates (same person) are possible TO CONFIRM.

Notebooks

loadFaceImages.ipynb: this notebook uses numpy, cv2. It defines load_face_images(filename, sampling=1, augmented=True). This function reads the .cdataset file and changes each image to grey. It changes each image to one vector in column order (order="F", MATLAB style, 486-dim). It returns (images float64 [N×486], labels). The augmentation uses np.roll, which moves edge pixels to the opposite edge.
gabor_feature_vector.ipynb: this notebook uses numpy, cv2, scipy.io.loadmat. It defines gabor_feature_vector(image). This function changes the image to uint8 and applies CLAHE (clip 2.0, tileGridSize (3,8)). It calculates a 32×32 FFT and multiplies it by the 5 scales × 8 orientations of G. It crops the magnitude of each iFFT to 27×18 and joins the results into 135×144. The output is a 19,440-dim vector. The input size must be 27×18.

gabor.mat

This is a MATLAB 5.0 file (created 31 Aug 2015). It has one key, G. G is a 5×8 object array of 32×32 Gabor filters in the frequency domain. The file has no ground-truth boxes.

Implications for our design

  • Use a detection window of 18×27 (W×H). This size agrees with the crops and the Gabor code.
  • Use a multi-scale image pyramid. The faces in im3 and im1 are larger than the detection window.
  • Examine im4. Its faces can be near or below the detection window size TO CONFIRM.
  • Correct the imbalance. After augmentation, the train set has 2.7 face images for each non-face image. Use class weights or change the augmentation.
  • Use hard-negative mining. Get more non-face images from areas without faces. A real detector sees many more non-face windows than face windows.
  • Normalise each detection window (zero mean and unit variance, or CLAHE as in the Gabor code). The lighting changes much, and the global mean does not separate the classes.
  • Use the same normalisation for training and for detection.
  • Use the train/test split from the files (94/30).
  • Report the metrics for each class. The test set has a ratio of 2:1.
  • Do not augment the test set (augmented=False).
  • Examine the data for identity leakage. The same person can be in the train set and the test set TO CONFIRM.
  • Use cross-validation on the train set to tune the model. The data set is small.
  • Use simple models (SVM, kNN) with strong features (HOG, Gabor). There are only 124 crops.
  • Use regularisation or PCA with the Gabor features. There are 19,440 features and only 94 train samples.
